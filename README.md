# SurfaLatte — bar & kitchen layout planner

Interactive equipment layout for the Albatross Surfboards + Coffee tenant
improvement at 28880 Roadside Drive, Agoura Hills, CA.

One self-contained HTML file. No build step, no dependencies, works offline.

Rooms, counter runs and equipment footprints are taken from the LA County
health-department equipment plans (sheet K-3) and the architect's set
(CD-2.1 / CD-2.2). Footprints marked with a `≈` come from manufacturer spec
sheets rather than a dimension printed on the drawings — field-verify before
ordering millwork.
